# Hello Project

Краткое консольное приложение на языке C#, которое генерирует случайные реалистичные данные (имя и адрес) на русском языке, выводит приветствие и текущую дату.

## Описание работы
Программа использует библиотеку `Bogus` с локализацией `"ru"` для генерации:
* Случайного полного имени и фамилии
* Случайного полного адреса

Также приложение выводит классическую строку "Hello, World!" и текущую дату в коротком формате.

## Инструкция по запуску

Для запуска проекта выполните следующую команду в терминале (находясь в папке с проектом):

```bash
git clone https://github.com/KaHiSTpA/MDK02.02.git
cd MDK02.02
dotnet restore
dotnet run
```
